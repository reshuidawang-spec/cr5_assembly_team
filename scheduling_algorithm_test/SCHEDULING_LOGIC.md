# 调度算法思路

当前测试使用“动态综合评分 + 滚动重调度”。

## 1. 固定工艺流程

单个产品内部工序不改变：

```text
R1 箱体上料
 -> R2 PCB 安装
 -> R3 控制模块安装
 -> R1 端子排安装
 -> R3 转移到检测平台
 -> CAMERA 相机检测
 -> NG：R4 锁付后由 R5 进行缺陷品分拣
 -> OK：R4 锁付，再由 R5 良品分拣
```

## 2. 动态调度流程

```text
读取订单
 -> 拆分数量订单为单件订单
 -> 生成固定工序 DAG
 -> 找出当前可执行任务
 -> 检查资源和共享区域
 -> 对候选任务进行综合评分
 -> 执行最高分任务
 -> 相机检测后生成 OK / NG 后续分支
 -> 新订单或急单插入后重新评分
```

## 3. 评分因素

综合评分考虑：

- 订单优先级；
- 交期紧急程度；
- 延期风险；
- 等待时间老化；
- 剩余关键路径；
- R3 瓶颈资源；
- 检测平台共享区域；
- 检测后清台；
- 急单临期加分。

这不是强制 A/B/C 交叉排序，而是根据评分逻辑决定订单顺序。

## 4. 质量分支

- NG：相机保存检测结果，R4 锁付后生成 R5 缺陷品分拣；
- OK：相机检测后先生成 R4 锁付，R4 完成后再生成 R5 良品分拣。

## 5. 指标

测试窗口和预览输出包含：

- Makespan；
- 冲突数；
- 急单响应时间；
- 急单完成时间；
- 加权延期；
- 检测平台平均驻留时间；
- 检测后平均等待清台时间。
